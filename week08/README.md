## 6/23 회의 — 추가 작업분 전달 (수집 범위 확정)
데이터랩스가 추가 수집분 전달. 산출물은 `md` / `리스트`로 구분.
- **① 대학 정보** — 경쟁률·입학정원·2026 경쟁률(수시/정시), 세부 모집인원 탭(학과 팝업+전형방법 열, 학과 1개=1행), [모집인원 변경사항] 팝업. + (우선순위 낮음) 전년 대비 주요 변경사항 md
- **② 학과 정보** — 학과소개 탭(교육목표·교육과정·진로취업분야). 밑작업: 대학·전형·학과 세부 코드 수집
- **③ 전형 정보** — 각 전형의 **전형일정및방법 탭**(전형일정·요소별반영비율·지원자격및기타·최저학력기준) + **전형요소 탭** 전부 ← **W09~W10 크롤러가 구현**

## ✅ 최종 작업분 (결정 3건) → W09~ 백로그
| 우선순위 | 작업 | 산출물 |
|---|---|---|
| 1️⃣ | 학생부 교과성적 반영방법 (진로까지) — 대표님 로직용 | 원본 + 정제① 국영사과 + 정제② 진로과목 ABC(LLM 점수화, A30/B20/C10) |
| 2️⃣ | 최저(최저학력기준) 정제 | 원본 + 정제 2종(교과계산기 `n합n` / 교과ON `국영수사과 2합5, 한국사 필수`) |
| 3️⃣ | 학생부 학년별/요소별 반영비율 | ①전형요소별반영비율 + ②학생부 학년별/요소별 이어붙임 |
