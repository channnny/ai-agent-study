# W06 — 3인 크롤러 통합 및 품질 개선

## 목표

W05에서 평가한 유찬·이지현·임지현 3개 어디가 크롤러 산출물을 하나의 canonical 데이터셋으로 통합한다.

- 커버리지: 한 소스라도 낸 대학·행은 보존한다.
- 셀 충진율: 한 소스라도 낸 셀은 최대한 채운다.
- 셀 일치율: Claude식 행 합집합/계보와 Codex식 W06 정규화를 결합하고, 전략 비교로 학습한 `유찬 → 임지현 → 이지현` 우선순위로 값을 선택한다.
- 리포트: W05와 유사한 지표(커버리지, 충진율, PK, 불일치셀, 누락·잉여)를 제공한다.

골든셋 값은 통합 데이터에 복사하지 않는다. 골든셋은 평가 리포트 생성에만 사용한다.

## 실행

```bash
cd week06
../week05/.venv/bin/python -m src.cli \
  --report-name evaluation_report_week06_codex.xlsx \
  --integrated-name integrated_crawler_week06_codex.xlsx
```

## 산출물

- `output/evaluation_report_week06_codex.xlsx`
  - `용어설명`
  - `종합`
  - `대학별`
  - `항목별`
  - `출처요약`
  - `미수집대학`
  - `누락·잉여`
  - `불일치셀`
  - `통합데이터`
  - `통합계보`
- `output/integrated_crawler_week06_codex.xlsx`
  - `canonical`: 최종 통합 데이터
  - `lineage`: 행·셀별 채택 출처와 후보값

## 최종 실행 결과

| 대상 | 셀 일치율 | 셀 충진율 | PK 매칭률 | 커버리지 |

| 유찬 | 97.22% | 84.23% | 70.39% | 100.0% |
| 이지현 | 95.90% | 93.15% | 70.87% | 97.8% |
| 임지현 | 97.34% | 94.72% | 76.26% | 98.2% |

통합본은 raw 최고 셀 일치율보다 약간 낮지만, 커버리지 100%와 높은 충진율을 유지하면서 PK 매칭률과 절대 수집량을 가장 크게 끌어올린다.
