# Week 06 — 3인 크롤러 통합 (커버리지·충진율·일치율 극대화)

W05의 3인(유찬·이지현·임지현) 어디가 크롤러 출력을 **하나의 통합 데이터셋**으로 병합하고,
W05와 동일한 지표로 **[통합 vs 3인]**을 비교한다.

## 한 줄 목표
> 누락되는 데이터 없이 **최대한 많은 데이터**를 모은다.
> = 커버리지(행) + 셀 충진율(값) + 셀 일치율(정확도)을 동시에 극대화.

## 빠른 실행
```bash
cd week06
python3 -m venv .venv && .venv/bin/pip install pandas openpyxl pyyaml pytest  # 최초 1회
.venv/bin/python -m src.cli \
  --report-name evaluation_report_week06.xlsx \
  --integrated-name integrated_crawler_week06.xlsx
```

## 산출물
- `output/evaluation_report_week06.xlsx` — 통합 vs 3인 비교 (7시트: 용어설명·종합·대학별·항목별·미수집대학·누락·잉여·불일치셀)
- `output/integrated_crawler_week06.xlsx` — 통합 canonical 데이터(22,480행) + 통합계보(셀 충돌 9,234건 추적)

## 통합 규칙 (`src/merger.py`)
1. **커버리지** — 한 명이라도 긁은 (대학·전형·모집단위) 행은 모두 포함 (행 합집합)
2. **충진율** — 같은 행에서 한 명이라도 값이 있으면 채움 (셀별 비어있지 않은 값 채택)
3. **일치율** — 같은 소스 내 PK 중복은 best_row(최다충진), 값이 갈리면 **항목별 신뢰도 우선**
   (반올림 허용 합의 인정). 전략 `trust|consensus|hybrid` (`--strategy`, 기본 trust)

> 골든셋 값은 병합에 쓰지 않는다 → 평가 독립성 유지.
