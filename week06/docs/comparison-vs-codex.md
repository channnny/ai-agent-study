# W06 통합 크롤러 성능 비교 — claude vs codex

같은 입력(W05 3인 산출물·골든셋·정규화 사전)과 **동일 평가 하니스**(`week05/src/matcher`)로
두 독립 구현(`week06-claude`, `week06-codex`)의 통합 결과를 비교한다.
각 구현은 자체 정규화기를 골든·크롤러 양쪽에 일관 적용하므로, 아래 수치는 "각 팀의 전체
파이프라인이 달성한 성능"이다. (측정 시점: 2026-06-08)

## 1. 통합(Integrated) 결과 — 핵심 지표

| 지표 | 🔵 claude | 🟠 codex | 우위 |
|---|---|---|---|
| **셀 일치율** (평가기준) | **96.90%** | 96.72% | claude +0.18%p |
| 커버리지 | 100.0% | 100.0% | 동률 |
| 셀 충진율 | 93.28% | 93.54% | codex +0.26%p |
| (참고) PK 매칭률 | **79.05%** | 78.50% | claude +0.55%p |
| matched 행 | **16,423** | 16,308 | claude +115 |
| 비교 셀(절대량) | **85,472** | 84,923 | claude +549 |

→ **claude가 셀 일치율·PK·matched·정답셀에서 우위**, codex는 충진율에서 근소 우위(±0.26%p).
   사실상 대등하나 핵심 지표(셀 일치율·절대 수집량)에서 claude가 앞선다.

## 2. 접근 방식 차이

| 항목 | claude | codex |
|---|---|---|
| 셀 선택 | 항목별 신뢰도 우선(trust) + 반올림 합의 | 신뢰도(전체0.5+항목0.3+대학0.2) 가중 |
| source 내 PK 중복 | best_row(최다충진) | best_row(최다충진) |
| 반영교과 정규화 | 과목 **집합 정렬**(약어·순서 흡수)+괄호주석 제거 | 전과목→전교과 + 일부 |
| **전형명 분류축 (교과)/(종합)** | **보존**(괄호·alias만 통일) | **제거**(축 strip) |

## 3. 핵심 설계 차이: 분류축 (교과)/(종합)

가장 큰 PK 격차 패턴은 `일반(교과) ↔ 일반`(248건) — 골든은 분류축을 달고, 크롤러는 떼고 나온다.

- **codex**: 축을 제거해 `일반(교과)`·`일반(종합)`·`일반`을 모두 `일반`으로 통일 → PK ↑.
  **부작용**: 크롤러가 **실제로 구분해 수집한** `농어촌(교과)`·`농어촌(종합)` 같은 별도 프로그램을
  **하나로 병합 → 데이터 손실**. (크롤러별 80건, 골든 내부 89건 충돌)
- **claude**: 축을 **보존**. 골든도 두 프로그램을 별도 행으로 유지하므로 **골든 granularity에 더 충실**.
  대신 `일반(교과)↔일반`은 "크롤러가 덜 세분화한" 진짜 격차로 남겨 둠(정규화로 가리지 않음).

실측(분류축 제거 실험): PK +3.7%p, matched +700행/인 vs 셀 일치율 −0.15%p이면서
**별도 프로그램 80건/인 병합 손실** 발생 → "누락 없이 최대한 많은 데이터" 목표에 反해 채택하지 않음.

claude는 분류축을 건드리지 않는 **안전한 전형명 정규화**(대괄호→소괄호, 전체 감싼 괄호 벗김,
오타 alias)만으로 PK 79.05%를 달성해 **codex(78.50%)를 데이터 손실 없이 상회**한다.

## 4. 교차 학습 요약

- claude ← codex: `best_row`, `_cells_equal` 반올림 합의, **trust-first 셀 선택**(다수결보다 정확).
- claude > codex: 반영교과 **과목집합 정규화**, 분류축 보존(데이터 충실), 안전 전형명 정규화로 PK 역전.
- 출발점 claude 94.2% / codex 95.53% → 양측 상호 학습 후 claude 96.90% / codex 96.72%.

## 5. 결론

두 구현 모두 통합 셀 일치율 ~96.8%로 수렴(목표 90% 크게 상회). **claude가 핵심 지표
(셀 일치율·PK·절대 정답셀)에서 근소 우위**이며, **분류축을 보존해 별도 프로그램을 잃지 않는
점에서 "누락 없이 최대 데이터" 목표에 더 부합**한다. codex는 충진율에서 동률 수준의 근소 우위.
