# Claude Code 작업 규칙

이 폴더는 회사 AI 에이전트 학습 동아리의 2주차 자료 정리 폴더입니다.

## 2주차 성격

2주차에는 Claude Code 실습이 없습니다. 조교 업무 매뉴얼 분석, 회의록, 업무 프로세스 맵, 추가 질문 목록 등 **문서 정리 중심**으로 진행됩니다.

## 작업 원칙

- 회의에서 나온 발언과 결정을 그대로 옮깁니다. 임의 보강·해석은 하지 않습니다.
- 미해결 질문과 답변이 나온 질문은 명확히 구분합니다.
- `대전모`, `통합본`, `어디가`, `데이터랩스` 등 도메인 용어는 그대로 사용합니다.
- 외부 첨부 파일(엑셀 등)은 파일명만 적고 링크는 걸지 않습니다.
