# 업무 프로세스 맵

## 목표

조교가 한 일을 아래처럼 한 줄 플로우로 복원하는 것.

```
대상 대학/모집단위 확인
→ 어디가에서 입결 데이터 조회
→ 필요한 값 수집
→ 엑셀 양식에 맞게 입력
→ 코드/전형/모집단위 매핑
→ 누락/예외 확인
→ 최종본 저장
```

---

## 실제 내용

```
수시 입결 (수시)
대학별 대전모 체크(어디가)
1. 대전모 테이블을 크롤
---> 크롤링 가능 여부 확인!!!
---> 업데이트 시점이 대학별로 다름 (이것도 자동화 가능 여부 체크)
2. 바이브온 폼에 맞게 파싱

수시 입결 (정시)
1. 어디가 1차
2. 대학에서 2차 확인
--> 어디가만 자동화 하는 것 고려
--> 이 작업의 예상 자동화 비율 (지현 : 40%)
--> AI 활용, 엑셀 정제

데이터랩스가 최종 정리한 파일이 아닌, 실제 조교가 작업하는 파일 확인 필요
```

---

## 업무 프로세스 맵 v0.1

```
1. 2026 대학-전형-모집단위 기준 파일 확인
2. 서비스 대상 대학/전형/모집단위 필터링
3. 어디가 사이트에서 해당 대학 검색
4. 전형/모집단위별 입결 데이터 확인
5. 필요한 지표를 엑셀 양식에 입력
6. 대학/전형/모집단위 코드 매핑
7. 누락/불일치 값 확인
8. 최종 통합본 저장
```

---

## 2회차 보강 (5/8 데이터랩스 회의 반영)

```
1. 학교별 데이터 정제
2. 이후 엑셀로 정리
→ 전형 결과 + [전형별 주요 사항]도 수집하면 좋음

5월말~6월중순 작업완료
→ 학교별로 자료는 업데이트 되어도, 종합 자료에는 반영이 늦을 수 있음
→ 학교별로 크롤링 하는 것이 좋을듯함

대학별 코드 두홍님이 전달 가능하다고 함
```
