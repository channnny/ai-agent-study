# 2주차 회의록

## 5/6 (수) 회의

- **참석**: 전원
- **논의 사항**: 조교가 하는 업무 파악하기

### 결정 사항

- 임지: 통합본(작업본) 컬럼별 어떤 값이 들어가고, 어떤 작업인지 정의
- 이지: 학수님과 금요일 회의 잡기 (회의 목표 설정)
- 유찬: 데이터랩스에 질문할 거리 만들기

### 조교 업무 리스트

```
→ 어디가에서 입결 데이터 조회
→ 필요한 값 수집
→ 엑셀 양식에 맞게 입력

어디가가 한번에 업데이트 하는게 아니라서 매주 업데이트
--------------------
→ 수시모집요강 파일, 대학 발표 자료 등 입결 데이터 조회
→ 엑셀 양식에 맞게 입력
대학마다 한번에 업데이트 하는게 아니라서 매주 업데이트
------------------
~~→ 코드/전형/모집단위 매핑~~
→ 누락/예외 확인
→ 최종본 저장
```

- 어디가 원본 화면/파일과 2025 완성본 사이의 매핑 규칙이 있는가? => X 상안님 확인 필요
~~- 대학명/모집단위명이 불일치할 때 조교는 어떤 기준으로 판단했는가?~~
- 수시와 정시는 같은 파이프라인으로 처리 가능한가? => X
~~- 파란열과, 흰색열의 차이가 무엇인가요?~~
- 어디가에 데이터 올라오는 url (전년도에 올라오는건지?) => O, 근데 크롤링은 학교별 페이지에서 학교별로

## 5/8 (금) 데이터랩스 회의

- 5월 말~6월 사이에 어디가 입결 나옴
  - 깔끔하게 나오지 않음
  - 입결 전형에서 전형방법(퍼센트)까지 같이 가져와야 함
  - url 내 대학코드만 바꿔주면 됨 → 전형별 탭 선택 → for문 사용해 크롤링
    - 대학별 폴더 생성, 그 안에 종합/교과/수능
- 어디가 전형별 주요사항 (산출방식) 같이 수집 - 폴더별로 따로 정리
- 필요한 것 - 모집요강에서 전형 추출 RAG 사용
  - 모든 pdf 를 쪼개고, '가천대 꺼 가지고 와'
  - 노트북LM 개념
