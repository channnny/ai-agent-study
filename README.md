# AI Agent Study

회사 학습 동아리용 AI 에이전트 실습 레포입니다.

## 전체 목표

매년 반복되는 조교 수작업 업무를 AI 에이전트로 대체하여 업무 효율성을 높이고, 실무 중심의 AI 활용 역량을 강화합니다.

대상 사이트는 대입정보포털 **어디가**(https://www.adiga.kr), 최종 산출물은 데이터랩스가 바로 쓰는 **입시 데이터 엑셀**입니다.

## 핵심 아키텍처: 두 갈래 처리

W03 설계서에서 확정된 분기. **두 갈래를 섞지 않습니다.**

- **A. 전형결과 → 엑셀** (구조화 가능, deterministic) — 모집인원·충원율·경쟁률·내신 입결을 코드로 파싱
- **B. 전형별 주요사항 → 원시 보존** (비정형, ambiguous) — 산출방식·예외 조건·안내문은 그대로 보존, 후속 LLM/RAG 처리 대상

## 작업 원칙

- **추측·환각 금지** — 원본에 없는 경쟁률·입결·등급을 생성하지 않음. 불명확하면 `확인 필요` 표기
- **deterministic vs ambiguous 분리** — 숫자 추출·코드 매핑은 코드/규칙, 줄글 요약·예외 해석은 LLM
- **HITL 유지** — 자동화하더라도 사람 검수 단계를 없애지 않음
- **개인정보 마스킹 선행** — 샘플은 마스킹 후 `input/`에 보관
