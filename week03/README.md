# 🟥 3주차 — 크롤링 설계서 작성

## 🎯 이번 주 목표

크롤링 작업 전, 대학별/전형별 모집요강 정리 방법을 **설계서로 확정한다.**
4주차에 "굴러가는" 크롤링을 만들 수 있도록 설계 디테일을 미리 박는다.

> ⚠️ **개인정보 처리 방침은 이 주차에 반드시 확정.** 늦어지면 11주차에 프로젝트가 멈출 수 있음.

## 👥 이번 주 역할별 할 일

| 역할 | 해야 할 일 |
| --- | --- |
| **공통** | 설계서 리뷰 및 승인, 성공 지표 합의, PRD/보안 가이드라인 확인 |
| **개발자 (유찬)** | 데이터 포맷별 파싱 난이도 조사, 어디가/대학별 페이지 구조 분석, 기술 스택 선정, 크롤링 테스트 환경 준비 |
| **기획자 A (품질)** | **전형별 주요사항 통 크롤링 변수 파악** (사진/표/페이지 구조 차이), 모범 줄글 샘플 5~10건 확보(few-shot용), 평가 기준 초안 |
| **기획자 B (프로세스)** | **대학별/전형별 모집요강 정리 방법 설계 주도**, 샘플 데이터 30~50건 수집 + 개인정보 마스킹 |

설계 분담: **이지현 각자 설계서를 만들어 유찬님께 전달**

## 🚀 진행 순서

1. **2주차 5/8 데이터랩스 회의 결과 재확인** ([week02/docs/meeting-notes.md](../week02/docs/meeting-notes.md))
2. 처리 방식 분리 정의
   - **전형결과** → 구조화 추출 가능 → 엑셀 생성
   - **전형별 주요사항** → 비정형(사진·표) → 통으로 크롤링
3. 대상 대학/전형 후보 리스트업 (두홍님이 전달한 대학별 코드 활용)
4. 이지현이 설계서 v1 작성 → 유찬님 전달
5. 샘플 30~50건 마스킹 후 `input/` 보관
6. 평가 기준 초안 + 보안 가이드라인 합의
