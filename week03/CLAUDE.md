# Claude Code 작업 규칙

이 폴더는 회사 AI 에이전트 학습 동아리의 3주차 폴더입니다.

## 3주차 성격

3주차는 크롤링 구현 **이전 단계**, 즉 **설계서 작성**이 중심입니다. 실제 크롤링은 4주차에 진행합니다. Claude Code는 다음 보조 작업에 활용합니다.

- 어디가/대학 페이지 구조 분석 메모 정리
- 설계서 초안 다듬기
- 샘플 데이터 마스킹 룰 점검

## 작업 원칙

- 대상 사이트(어디가, 대학별 페이지)의 변수(사진/표/페이지 구조 차이)를 빠짐없이 정리합니다.
- **전형결과(구조화 가능)**와 **전형별 주요사항(비정형)** 처리 방식을 분리해 설계합니다.
- 샘플 데이터는 개인정보 마스킹을 완료한 뒤 `input/`에 보관합니다.
- 설계서는 이지현이 각자 작성하고, 유찬에게 전달한 후 비교·통합합니다.
- 원본 사이트 구조에 없는 내용을 추측해서 설계에 적지 않습니다. 모르는 항목은 `확인 필요`로 표기합니다.
