# 품질 평가 기준 초안

크롤링 결과를 사람이 검수할 때 사용하는 기준입니다. 4주차 검수 단계에서 그대로 사용합니다.

---

## 평가 항목

| 항목 | 기준 | 결과 |
| --- | --- | --- |
| 원본 충실도 | 어디가/모집요강 원본과 값이 일치하는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 누락 여부 | 모집인원, 전형명, 경쟁률 등 핵심 필드가 빠지지 않았는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 추측 여부 | 원본에 없는 값(임의 추정치 등)이 만들어지지 않았는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 표 변형 처리 | 병합 셀/행 변경 등에서 값이 어긋나지 않았는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 사진/표(주요사항) 보존 | 비정형 자료가 통째로 잘 저장되었는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 마스킹 | 개인정보가 그대로 노출되지 않았는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |
| 명명 규칙 | 파일명/시트명이 합의된 규칙을 따르는가 | ⬜ 좋음 / ⬜ 보통 / ⬜ 나쁨 |

---

## 부적합 출력 분류

- **A: 즉시 폐기** — 추측·환각/개인정보 노출
- **B: 재실행 필요** — 누락/포맷 오류
- **C: 사람 보정 필요** — 표 변형, 일부 셀만 어긋남
