# 출력 데이터 포맷

크롤링 결과의 두 갈래(전형결과 / 전형별 주요사항)에 대한 출력 스펙입니다.

---

## A. 전형결과 — 엑셀

- 파일 경로: `output/<대학>_<전형구분>.xlsx`
- 시트: 전형별로 분리하거나 한 시트에 컬럼으로 구분 (논의 후 결정)

### 컬럼 후보 (2주차 통합본 기준)

| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| 작업자 | string |  |

| 대학명 | string |  |

| 통합발표코드 | string |  |
| 모집단위 | string |  |
| 모집인원 | int |  |
| 전형명 | string |  |
| 충원율 | float |  |
| 예비번호(충원인원) | int |  |

| 실질경쟁률 | float |  |

> 컬럼 추가/제거 결정 시 본 문서 갱신.

---

## B. 전형별 주요사항 — 원시 데이터

- 파일 경로: `output/<대학>/<전형>/<원본파일명>.{html|pdf|png}`
- 메타데이터 파일: `output/<대학>/<전형>/_meta.json`

### `_meta.json` 예시

```json
{
  "university": "",
  "universityCode": "",
  "admissionType": "",
  "sourceUrl": "",
  "fetchedAt": "",
  "files": [
    { "filename": "", "type": "html|pdf|image", "note": "" }
  ],
  "needsReview": []
}
```

> 본문 추출/표 구조화는 다음 단계(RAG 등) 과제로 분리.

---

## C. 명명 규칙

- 대학명: 공식 한글 명칭 사용 (예: `가천대학교`)
- 전형구분 코드: `종합`, `교과`, `수능`, `논술`, `정시` 등 합의된 키만 사용
- 파일명에는 공백 대신 `_` 사용
