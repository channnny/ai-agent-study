## 2. A. 전형결과 (구조화 → 엑셀)

- 출처: 어디가 (대학코드만 바꿔서 전형별 탭 순회)
- URL 패턴: `https://....{대학코드}....`
- 수집 필드: 모집인원, 충원율, 경쟁률, 내신 입결 등
- 출력 포맷: 엑셀 (`output/<대학>_<전형구분>.xlsx`) — [docs/data-format.md](data-format.md) 참고
- 동작 흐름

```
대학코드 입력
→ 어디가 페이지 진입
→ 전형 탭 순회 (종합/교과/수능)
→ 표 파싱
→ 엑셀 시트로 저장
```

- 변수/예외
  - 업데이트 시점이 대학별로 다름
  - 전형 탭 구조가 통일되지 않을 가능성
  - 표 행 수/병합 셀 변형
- 자동화 대상 비율 추정: %

---

## 3. B. 전형별 주요사항 (비정형 → 통 크롤링)

- 출처: 대학별 모집요강 페이지 또는 PDF
- 형태: 본문 텍스트 + **사진/표/이미지** 혼재
- 출력 포맷: 원시 데이터 그대로 보존 (HTML/PDF/이미지)
  - 폴더 구조: `output/<대학>/<전형>/<원본파일명>`
- 변수/예외
  - 사진으로 된 표
  - PDF 내부 표/그림 영역
  - 모집요강 페이지 구조 차이
- 후속 처리(4주차 또는 그 이후): RAG / 모델 처리 검토
