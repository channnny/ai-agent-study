# 3주차 세부 체크리스트

## 공통

- [ ] 5/8 데이터랩스 회의 결과 재확인
- [ ] 처리 갈래 분리 합의 (전형결과 / 전형별 주요사항)
- [ ] 설계서 v1 리뷰
- [ ] 성공 지표 합의
- [ ] 보안 가이드라인 확인서

## 개발자 (유찬)

- [ ] 어디가 페이지 구조 분석 메모 (URL 패턴, 탭 구조, DOM 후보)
- [ ] 대학별 모집요강 페이지 구조 표본 분석 (5개 대학)
- [ ] 데이터 포맷별 파싱 난이도 조사 (HTML/표/PDF/이미지)
- [ ] 기술 스택 선정안 (예: requests + BeautifulSoup, Playwright, OCR 등)
- [ ] 4주차 테스트 환경 사전 점검 (실행 위치, 의존성)

## 기획자 A (품질)

- [ ] 전형별 주요사항 통 크롤링 변수 파악 (사진/표/페이지 차이)
- [ ] 모범 줄글/표 샘플 5~10건 확보
- [ ] 평가 기준 초안 → docs/quality-criteria.md
- [ ] 부적합 출력 분류 합의

## 기획자 B (프로세스)

- [ ] 대학별/전형별 모집요강 정리 방법 설계 → docs/crawl-design-spec.md
- [ ] 샘플 30~50건 수집
- [ ] 개인정보 마스킹 규칙 + 마스킹 실행
- [ ] 마스킹 완료본 input/ 보관
- [ ] 대상 대학/전형 리스트 → docs/target-universities.md
