## 📊 첫 실행 결과 (회의 토론용)

| 사람 | PK 매칭률 | 셀 일치율 | 커버리지 | DoD |
|---|---|---|---|---|
| 유찬 | 35.8% | 54.9% | 76.0% (146/172 대학) | ✗ |
| 이지현 | 41.4% | 37.9% | 89.7% (157/172 대학) | ✗ |
| 임지현 | 4.3% | 48.3% | 4.7% (8/172 대학) | ✗ |

DoD 임계치 (PK ≥ 85% / Cell ≥ 90%) 미달. **회의 토론 포인트**:
1. **전형 카테고리 분류 차이** — 예: 골든 `특성화고교(종합)` vs 이지현 `특성화고교`, `학생부우수자` 등 분류 기준 자체가 다름. 정규화로 해결 불가, 합의 필요.
2. **유찬 복잡 테이블 스킵** — 단과대학+모집단위 패턴(경북대 등) 316개 스킵 → W06 어댑터 보강 시 ↑.
3. **임지현 커버리지 4.7%** — 기존 zip의 8대학만. 본인 키 보호 차원에서 재실행 안 함. 회의에서 향후 처리 방향 논의.
4. **셀 일치율이 PK 매칭률보다 낮은 사례** — 이지현 PK 41% / Cell 37% → matched 행 안에서도 셀 값 불일치 빈도가 높음. 정규화 사전 9섹션 중 4섹션만 적용 한계.
