# 🟧 4주차 — 크롤링 굴러가게 만들기

## 🎯 이번 주 목표

3주차 설계서를 들고 **실제 크롤링을 돌려 데이터를 넣는다.** 일단 굴러가게만.
완성도보다 동작 확인이 우선. 결과는 2지현이 검수하면서 보완점을 잡는다.

## 👥 이번 주 역할별 할 일

| 역할 | 해야 할 일 |
| --- | --- |
| **공통** | Anthropic 프롬프트 가이드 함께 학습, 결과 데이터 검수, 보완점 합의 |
| **개발자 (유찬)** | **3주차 설계서 기반 크롤링 테스트 구현**, 토큰/비용 등 코드 이식 제약 사전 조사 |
| **기획자 A (품질)** | **프롬프트 v1 작성 주도**(필요 시), Claude.ai 웹에서 샘플 테스트, 결과 데이터 품질 검수, 부적합 출력 플래깅 |
| **기획자 B (프로세스)** | 2지현 함께 검수하며 **프로세스 보완점 도출**, 실무 관점에서 부적합한 출력 사례 수집 |

검수 분담: **2지현 함께 결과를 보면서 보완점 찾기**

## 🚀 진행 순서

1. **3주차 설계서 재확인** ([week03/docs/crawl-design-spec.md](../week03/docs/crawl-design-spec.md))
2. 1차 표본(5건 정도)로 크롤링 시도 → 동작 확인
3. 표본 결과 저장
   - **전형결과** → 엑셀(`output/<대학>_<전형구분>.xlsx`)
   - **전형별 주요사항** → 원시 데이터(`output/<대학>/<전형>/...`)
4. 2지현 검수 → 부적합 사례 수집 → docs/review-findings.md
5. 1차 보완 후 표본 확장 (10~30건)
6. 최소 10건의 수동 테스트 결과 기록
7. 5주차로 이월할 보완 항목 정리
