# Claude Code 작업 규칙

이 폴더는 회사 AI 에이전트 학습 동아리의 4주차 폴더입니다.

## 4주차 성격

4주차는 3주차 설계서 기반 **크롤링 테스트 구현 주차**입니다. 목표는 "굴러가게만". 완성도 욕심보다 **동작 확인 + 부적합 사례 수집**이 우선입니다.

## 작업 원칙

- **3주차 설계서가 단일 진실원**입니다(`week03/docs/crawl-design-spec.md`). 임의 변경 시 반드시 기록(`docs/review-findings.md`).
- **두 갈래를 분리**해 진행합니다.
  - 전형결과 → 엑셀 생성 (`output/<대학>_<전형구분>.xlsx`)
  - 전형별 주요사항 → 원시 크롤링(HTML/PDF/이미지) 그대로 보존
- 표본은 작게 시작합니다(5건 → 10~30건). 처음부터 전량 돌리지 않습니다.
- 부적합 출력은 즉시 폐기하지 말고 분류해서 보관합니다 — 5주차 개선 인풋입니다.
- **추측·환각 금지**: 원본에 없는 값(임의 추정 경쟁률·예상 입결 등)이 들어가면 즉시 플래그.
- 토큰/비용이 걸리는 작업은 표본만 먼저 돌리고 비용을 기록합니다.

## 검수 절차

1. 결과 파일 생성 → 검수자에게 알림
2. 이지현이 함께 검수 (`docs/quality-criteria.md` 기준 적용)
3. 부적합 사례 → `docs/review-findings.md`에 분류(A/B/C)와 함께 기록
4. 재실행 필요 항목은 다시 돌림 (프로세스 자체에 문제가 있다면 설계서 보강)
