# 전형정보 정제 프로그램 — 설계 (W11)

> 목적: 전형정보 크롤 **통합본**(2시트 RAW)을 입력받아, 사용자 화면(교과내신계산기·교과ON·
> 교과ON리포트)에서 바로 쓸 수 있는 **정제 데이터**를 **시트3**으로 추가한다. 참고 산출물
> `전형정보_통합_정제.xlsx`(6대학·1,353행, 클로드코드 정제)와 **양식 동일**. **순수 결정적**(LLM 없음).

## 근거 자료 (week11/input/)
- `README_핸드오프.md` — 프로젝트 개요·6종·결정사항·미해결이슈
- `정제룰_정의서.xlsx > 정제룰` — 규칙 SSOT(21행)
- `reference_전형정보_통합_정제.xlsx > 정제` — **골드셋 1,353행**(회귀 검증 기준)
- `정제_검증샘플_4대학.xlsx > 검증노트` — 케이스별 판단(가톨릭·남서울·가야·단국)

## 결정 사항 (사용자 승인)
- **엔진 = 순수 결정적** (규칙/regex, LLM 없음). 재현성 100%·무비용.
- 난케이스는 오답 대신 **`검증필요:<사유>`** 플래그 → 사람 리뷰(침묵 오류 금지).
- 성공 기준 = **골드셋 회귀** 셀단위 대조.

## 2. RAW 소스 컬럼 매핑 (1-based)
- **시트1 전형일정및방법**: `15 선발모형·16 선발방법·17 선발비율%·18 학생부·19 수능·20 면접·21 논술·22 적성·23 1단계성적·24 실기·25 서류·26 기타·27 기타내용`(→5a) · `35~44 최저 국수영탐제2한·45 반영영역수·46 세부내용`(→①②)
- **시트2 전형요소**: `33~38 학년(공통/1/2/3)·39~44 요소(교과·출결·자격·활동·봉사·기타)`(→5b) · `45~48 서류(학교생활기록부·특기자실적…)`(종합 판별) · `50 반영교과·53 진로선택·55 반영교과및반영방법`(→③④)

## 3. 정제 규칙 (정제룰 SSOT + 검증노트)

### ③ 교과반영영역 (`gyogwa.py`)
- col50 반영교과 distinct → **국영수사과한** 순 축약. 역사/도덕→`사` 흡수, 한국사 별도교과→`한`.
- 예: `국어/수학/영어/사회(역사/도덕포함)/과학/한국사` → `국영수사과한`. 가천대(한국사 없음)=`국영수사`.
- 종합전형·반영교과 없음 → `해당없음(종합)` / `미반영`.

### 5a 전형요소별비율 (`ratio.py`)
- 선발모형 2종: **일괄** / **단계**. 퍼센트 괄호없이 숫자, 단계 사이 `;`(공백X), 요소합산 `+`, 배수 정수+`배수`.
- 방법명: `1단계성적→1단계` · 교과전형 학생부→요소별분해(교과·출결·교과정량·교과정성) · **종합=서류** · 그 외(면접·실기·논술·적성) 그대로.
- `[일괄]교과90+출결10` / `[1단계(3배수)]서류100;[2단계]1단계60+면접40`. 단일요소도 `[일괄]` 부기.

### 5b 학년별/요소별비율 (`ratio.py`)
- `[학년]…[요소]…`. 학년공통=`전학년공통N`, 분리=`1학년N·2학년N·3학년N`. 요소=`교과N·출결N…`.
- **합≠100 → `검증필요:5b합<n>`**.

### ①② 수능최저 (`choi.py`)
- 미입력(`대학에서 입력된 정보가 없습니다`/공란) → **`최저 없음`**(①②둘다).
- ② 영역조합: 영역순서 **국→수→영→[탐/사/과]** 고정. 탐구 사탐만=`사`·과탐만=`과`·둘다=`탐`. 탐구 (1)/(2)=최상위1과목/2과목평균. 한국사 **등급컷 있을 때만** `한N`. `!` 무시. 필수영역 `(수 포함)`/`(수,과 포함)`.
  - 예: `국,수,영,탐(1) 중 2개 등급합 6`.
- ① N합N: ②에서 n·m 추출 → `2합6`.
- **비정형 최저 문구(파서 미매칭) → `검증필요:최저파싱`** (원본 셀은 [원본] 컬럼에 보존).

### ④ 진로 A/B/C (`jinro.py`)
- col55 각주에서 환산표 파싱, 5유형: ①등급환산 `A=1,B=3,C=5등급` ②점수 `A=100,B=80,C=60점` ③가산 `A=5,B=3,C=1점(가산점)` ④병기 ⑤비율연동(정규화불가→원문).
- 진로칸(col53) 공란 → `미반영`. 진로 채워졌으나 각주 환산표 없음 → **`내부확인`**(소스 미노출, README 이슈1).
- 종합전형 → `해당없음(종합)`.

### 종합전형 판별 (`jonghap.py`)
- 판별: 전형명에 `종합` 포함 **또는** 시트2 서류평가요소(col45 학교생활기록부) 채워짐 & 교과반영방법 없음.
- 종합 → ③·④·5b = `해당없음(종합)`, 5a = `[일괄]서류100`(서류 매핑).

### 공통 컨벤션
- **fill-down**: 전형-공통 필드(반영비율·학년요소)는 모집단위 row마다 채움. 최저 등 상이 필드는 각 모집단위 크롤값.
- **1:N 직렬화**: 행간 `|`, 셀내 다중값 `,`.
- 빈값: [원본]=공란 보존, [정제]=의미값(`최저 없음`/`미반영`/`해당없음`).

## 4. 아키텍처 (모듈 = 정제항목별 단일 책임)
```
week11/scripts/refine/
  sources.py   RAW 2시트 read → 모집단위 dict + [원본] 직렬화 컬럼 생성
  gyogwa.py    ③   교과반영영역
  ratio.py     5a·5b 반영비율
  choi.py      ①②  수능최저
  jinro.py     ④   진로 A/B/C
  jonghap.py   종합전형 판별 + 종합 규칙
  build.py     오케스트레이션: 입력 → 정제 → 시트3 append → 저장
  validate.py  골드 대조 리포트
```
- 각 파서 = 순수함수(입력 dict → 출력 str | `검증필요:…`), 독립 테스트 가능.
- `build.py`만 openpyxl I/O. 파서는 문자열 in/out.

## 5. 검증 (핑퐁 방지 2축)
1. **검증필요 플래그** — 파서 미확신(최저 비정형·진로 비정형·5b합≠100)은 `검증필요:<사유>` 출력. 배포 전 이 셀만 모아 사람 리뷰.
2. **골드 회귀** — `validate.py`가 프로그램 출력 시트3 vs `reference…정제.xlsx` 골드 시트3(1,353행)을 **adiga_selcntnm 키로 셀단위 대조**. 산출: 항목별 일치율 + 불일치 목록 + 검증필요 건수. 알려진 예외(진로 소스 미노출 등)는 화이트리스트로 문서화.
