# 어디가 전형정보 정제 프로젝트 — 핸드오프

## 1. 프로젝트 개요

어디가(adiga.kr) **[전형정보]** 의 원본 데이터를 크롤링하고, 사용자 화면(교과내신계산기·교과ON·교과ON리포트 등)에서 바로 쓸 수 있도록 **일관된 포맷으로 정제**하는 프로젝트입니다. 크롤 스키마 정의 → 정제 규칙 확정 → 클로드코드 대량 정제 → 실데이터 검증 순으로 진행했습니다.

## 2. 산출물 파일

| 파일 | 역할 |
|---|---|
| `전형정보_통합_정제.xlsx` | **메인 결과물**. 1,353개 모집단위(6개 대학). 시트1·2 = 어디가 크롤 원본(RAW), 시트3 = 정제룰 적용해 클로드코드로 정제 완료 |
| `정제룰_정의서.xlsx` | 크롤 스키마 + 6개 정제 규칙의 **원본 정의(SSOT)**. `정제룰` 시트에 파싱 규칙 전문 수록 |
| `정제_검증샘플_4대학.xlsx` | 가톨릭대·남서울대·가야대·단국대 실데이터로 룰 검증. `검증노트` 시트에 케이스별 판단·이슈 기록 |

### 메인 파일 시트 구조
- **시트1 전형일정및방법 / 시트2 전형요소** — 어디가 실제 크롤 원본(RAW). 절대 손대지 말 것(재크롤 시 덮어쓰기 대상).
- **시트3 정제** — 정제 결과. `[원본]` 컬럼과 `[정제]` 컬럼이 페어로 배치되어 추적 가능. 정제 대상 6종을 담음.

## 3. 정제 데이터 6종

| 항목 | 출력 예시 | 사용처 |
|---|---|---|
| ① N합N | `2합6` / `최저 없음` | 교과내신계산기 |
| ② 영역조합 | `국,수,영,탐(1) 중 2개 등급합 6` | 교과ON |
| ③ 교과반영영역 | `국영수사과한` | 교과ON리포트 |
| ④ 진로 A/B/C | `A=1,B=3,C=5등급` | 내부확인용 |
| 5a 전형요소별 비율 | `[일괄]교과90+출결10` / `[1단계(3배수)]서류100;[2단계]1단계60+면접40` | - |
| 5b 학년별/요소별 비율 | `[학년]전학년공통100 [요소]교과100` | - |

## 4. 확정된 규칙·결정사항

- **수능최저 영역순서 고정**: 국 → 수 → 영 → [탐/사/과]. 탐구 사탐만=사, 과탐만=과, 둘 다=탐.
- **탐구 (1)/(2)**: 최상위 1과목=(1), 2과목 평균=(2). **한국사는 등급컷 있을 때만** `한N` 부기(응시 필수 ≠ 등급컷).
- **`!` 표기 무시**. 최저 미입력이면 `최저 없음`.
- **1:N 필드 직렬화**: 교과성적 반영방법·지원자격 등은 한 셀에 직렬화. 행간 `|`, 셀 내 다중값 `,`.
- **RAW / 정제 분리 저장**: RAW는 verbatim 보존, 정제는 파생·재생성.
- **5a 방법명 규칙**: 종합=`서류`, 교과전형 학생부→요소별(`교과`·출결·교과정량·교과정성)로 분해, `1단계성적→1단계`. 퍼센트는 괄호 없이 숫자, 단계 사이 `;`, 요소 합산 `+`, 배수는 정수+`배수`.
- **모집단위 fill-down**: 전형-공통 값은 모집단위 row마다 전부 채움. 최저 등 모집단위별 상이 필드는 각자 크롤값.

> 규칙 전문·예시는 `정제룰_정의서.xlsx > 정제룰` 시트 참조.

## 5. 미해결 이슈 / 주의사항 (합류 전 반드시 확인)

1. **④ 진로 A/B/C 소스 불안정** — A/B/C 환산표가 대학마다 각주에 노출되기도(남서울·가야) 안 되기도(가톨릭) 합니다. 정제 1,353건 중 **1,311건이 해당없음/내부확인** → 소스 커버리지가 낮습니다. 어디가 외 소스(대학 모집요강) 보완 검토 필요.
2. **종합전형 스키마 상이** — 종합전형(예: 단국대)은 전형요소 탭이 **"서류 평가요소(학교생활기록부/특기자실적 O/X)"** 구조라 교과전형용 시트2와 다릅니다. 종합에서는 ③·④·5b가 모두 `해당없음`. 종합전형용 별도 처리 규칙이 필요합니다.
3. **단계별 전형** — 실데이터 정제에서 **265건**이 단계별로 출력됐습니다. 다만 1단계 배수의 RAW 소스 매핑은 샘플 단위 검증을 못 했으니 **스팟체크 권장**.
